Reflected XSS via URL Parameter

Pass a payload via the ?payload= query parameter. The value is rendered directly into the DOM without sanitization.

DOM-based XSS via URL Fragment

Type payload below and submit. The input is reflected back into the DOM without encoding, simulating a stored/reflected XSS in a comment field.

Usage

1. Reflected: ?payload=<script>alert(1)</script>
