CSRF Proof of Concept

Target Configuration

GET GET Request Forgery

An <img> tag makes a cross-origin GET request when the page loads. The browser sends cookies automatically.

Ready. Configure the target URL and click "Send GET Request".

HTML Payload (for victim)

How it works: The img tag below auto-fires when rendered. The browser attaches cookies for the target domain automatically.
Note: CORS does not block <img> tags — the request is sent; only the response cannot be read.

POST POST Request Forgery

An auto-submitting HTML form sends a POST request across origins. The browser includes cookies for the target domain.

Ready. Configure the target URL + parameters and click "Send POST Request".

HTML Payload (for victim)

How it works: A hidden form with action set to the target URL is auto-submitted via JavaScript (form.submit()). The browser sends cookies automatically.
Note: Form-based POST cross-origin works even without CORS headers.

Usage

1. Set the Target URL to the endpoint you want to attack
2. For POST CSRF, add parameters (one per line, key=value)
3. Click Send GET/POST Request to execute the CSRF
4. Use the generated HTML payload as a phishing page for the victim

Tip: You can also save the generated HTML as a standalone file and host it anywhere.
